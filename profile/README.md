### 加入我们

Kaeman-Dev 正在开发一个全新的 Hypixel SkyBlock Bot 项目，希望找到对这一方向感兴趣，并愿意参与项目设计、开发与长期维护的开发者和设计者

Kaeman 是一个**无偿的开源项目**，目前不会提供工资或其他形式的经济报酬。我们不会过度看重履历或已有项目经验，更关注你是否对项目本身感兴趣，以及是否愿意真正参与开发、讨论和维护

参与 Kaeman，你可以接触到多人协作下较完整的项目开发流程，包括架构设计、功能实现、Code Review、Issue / PR 协作、长期维护、重构、兼容性处理以及项目管理等

## 技术栈

Kaeman 主服务目前主要使用 **TypeScript + Koishi** 开发

对于独立服务，我们不限制具体编程语言。你可以根据实际需求选择合适的技术栈，并通过 **gRPC** 与 Kaeman 主服务及其他服务通信

Kaeman 的 Public API 主要使用 **Go + Gin** 开发，用于向外部应用、Minecraft Mod 以及其他服务提供统一接口

前端及图片渲染相关部分主要使用 **Vite + Vue 3 + SCSS**

我们同样计划开发适用于 **Minecraft 26.x** 的 Fabric Mod，使其能够直接与 Kaeman 提供的 API 和服务进行交互

## 我们正在寻找

- **Koishi / TypeScript 开发者**  
    参与 Kaeman 主服务及核心组件的开发与维护，包括 处理社交平台(例如QQ)发送的Command, 并编写处理逻辑、业务功能以及与其他 gRPC 服务的对接
    
- **Public API 后端开发者**  
    使用 Go + Gin 开发和维护 Kaeman Public API，负责主服务、其他内部服务与外部客户端之间的接口
    
- **前端开发者**  
    处理 Kaeman 及其他服务提供的数据，开发 Web 界面和图片渲染功能
    
- **Minecraft 26.x Fabric Mod 开发者**  
    对接 Kaeman Public API，将 Kaeman 的部分功能集成到 SkyBlock 客户端中
    
- **UI / UX 设计者**  
    参与 Kaeman 整体视觉语言、界面设计、交互方式及 UI / UX 风格的建立与完善
    
- **运维与部署维护人员**  
    负责服务部署、运行环境、监控及相关基础设施维护
    
- **系统与项目架构设计者**  
    参与服务拆分、通信方式、数据流及整体项目架构设计
    
- **其他愿意参与 Kaeman 生态开发与维护的开发者**
    

我们不要求你已经具备大型项目开发经验，也不要求掌握上述所有技术。只要你对其中某个方向感兴趣，愿意学习、交流并实际参与项目，就可以加入

如果你也对从零构建一个新的 SkyBlock Bot 及其周边生态感兴趣，欢迎加入 Kaeman-Dev
